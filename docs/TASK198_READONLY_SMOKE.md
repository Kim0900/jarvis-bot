## 실행 (허가가 열린 뒤)
```
SUPABASE_URL=... SUPABASE_KEY=... SUPABASE_INTERNAL_RPC_SECRET=... \
  python tests/live_smoke_task198_readonly.py --not-after 2026-10-20T14:00:00+09:00 --report smoke_report.json
```
`--not-after`는 필수이며(허가 창의 끝, UTC 오프셋 포함), 그 시각 이후에는 요청을 보내지 않는다. 비밀값은 환경변수로만 주입하고 출력·보고서에 남지 않는다. 내부 RPC 비밀이 없으면 `call_image_ingestions` 점검 2건은 `NOT RUN`(통과로 세지 않음, 종료 코드 1)이다.
